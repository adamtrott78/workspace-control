## Candidate C1 — Scientific outcome partition exhaustiveness\n\nStatus: **SUPPORTED CANDIDATE — NOT GOVERNING**\n\nMeta-experiment result: `CANDIDATE_SUPPORTED` under Workspace Control Validation `40139618613`. The generic enumeration found the original missing state and the corrected design covered the full finite valid-state partition with zero overlaps.

### Residual

v0.1 requires predeclared outcome interpretations, but it does not explicitly require the valid scientific outcome space to be both:

1. exhaustive; and
2. mutually exclusive.

The current EXTRACT composition design supplied a positive control for this defect. Its first frozen table covered:

- 7/7 controls + both residuals → ROBUST or FRAGILE;
- 7/7 controls + exactly one residual → PARTIAL;
- loss of a control → COLLISION;
- invalid execution → INVALID_EXECUTION.

It omitted the valid scientific state:

```text
execution valid
controls retained = 7/7
e1.a = absent
e6.a = absent
```

The design was corrected before implementation by adding `COMPOSITION_NEGATIVE`.

### Proposed v0.2 rule

Every frozen experiment MUST establish **verdict-space totality** before implementation.

For a finite/discrete outcome space:

- declare decision-relevant scientific outcome dimensions;
- explicitly separate scientific dimensions from execution-invalidity dimensions;
- enumerate or symbolically cover all valid combinations;
- require every valid scientific state to map to exactly one verdict;
- reject uncovered states;
- reject overlapping verdicts unless explicit precedence is itself part of the frozen design.

For continuous or large outcome spaces:

- define ordered predicates or mutually exclusive regions;
- require an explicit final scientific catch-all for valid executions;
- keep operational invalidity outside the negative scientific catch-all.

## Candidate C2 — Diagnostic depth before architecture commitment

### Residual

The first prospective methodology shadow correctly interpreted `ADDITIVE_FRONTIER_PARTIAL`, but its next-action wording moved too quickly toward comparing architecture families.

EXTRACT instead inserted a cheaper exposure diagnostic and learned that e1.a was `SHALLOW_DISTRIBUTED_EXPOSURE`.

### Proposed v0.2 rule

After every valid scientific result:

1. reconstruct the residual and live hypotheses;
2. identify the next decision-relevant uncertainty;
3. ask whether a lower-cost diagnostic can discriminate that uncertainty;
4. prefer the diagnostic when it can materially alter the next decision;
5. only then select a larger architecture family.

A frozen outcome's `authorized_next_action` defines an **admissible scientific region**, not a mandatory implementation.

Status: **SUPPORTED CANDIDATE; requires more prospective cases before adoption.**

## Candidate C3 — Contamination-aware architecture-selection validation

### Residual

A methodology recommendation placed in shared state before the EXTRACT owner selects a design can alter that design. Agreement afterward is not independent validation.

### Proposed v0.2 rule

Architecture-selection validation requires an isolated commitment mechanism.

Until one exists:

- shared pre-design methodology recommendations may guide science;
- but resulting architecture agreement MUST be classified `NOT_EVALUABLE` for independence.

A future blind dual-lane protocol should commit the methodology recommendation before reveal and preserve exact identity.

Status: **OPEN CANDIDATE.**

## Candidate C4 — Explicit steady-state overhead telemetry

### Residual

v0.1 requires acceptable coordination overhead but does not yet define how to measure it.

### Proposed prospective measures

Per scientific boundary record:

- methodology-specific blocking stops;
- methodology-specific PRs/commits;
- extra human coordination steps;
- elapsed wall-clock attributable to methodology gates where observable;
- invalid experiments or repeated mechanism work plausibly prevented, recorded separately as non-causal observations;
- whether methodology work occurred at a scientific boundary or leaked into routine engineering.

Do not fabricate counterfactual time savings.

Status: **OPEN CANDIDATE.**
