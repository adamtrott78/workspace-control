# Course assignment-work procedure

## Purpose

Coordinate assignment learning, completion, artifact production, and persistence
without conflating assignment completion with student mastery.

## Procedure

1. Load the exact project-owned assignment/source and deliverable rules.
2. Recover assignment completion state and mastery state as separate axes.
3. Select the tutoring mode from user intent and durable state.
4. Execute learning through `procedures/course_study_session.md`, or authorized
   substantive completion work under COMPLETION semantics.
5. Build required project artifacts; apply
   `procedures/document_artifact_build.md` for document deliverables and the
   assignment's reproducibility contract for code/results.
6. Persist what was independent, guided, or executor-generated separately.
7. Validate requirements, artifacts, reproducibility, and learning state
   independently.

External submission, message sending, destructive changes, and ambiguous
high-impact requirement choices remain project/user gates.
