# Course study-session procedure

## Purpose

Execute one durable repository-backed learning session using the shared tutoring
contract.

## Procedure

1. Recover relevant scope, dependencies, mastery, prior history when material,
   notation/source authority, and persistence scope.
2. Diagnose with the smallest question that localizes the earliest blocking or
   unassessed dependency. Unassessed is not weak.
3. Teach the smallest missing unit and return control to the student.
4. Require application/transfer that supports the claimed mastery transition;
   tutor-generated work is not independent evidence.
5. Persist project-owned learning/mastery evidence at a meaningful boundary
   under the shared operator workflow.

Use LEARNING, COMPLETION, MASTERY_RECOVERY, and EXAM_READINESS semantics from
`policies/TUTORING_CONTRACT.md`. Completion must not cross the
completion/mastery firewall.

A session may end with unresolved skills, but durable state must make the next
diagnostic recoverable without the conversation.
